# Our Story

This app runs on React + TypeScript + Vite and now uses Supabase for:

- Authentication (email and Google)
- Realtime shared data sync
- Media uploads (images/audio)

## Setup

1. Install dependencies:

```bash
npm install
```

2. Copy environment template:

```bash
cp .env.example .env.local
```

3. Configure Supabase by following [SUPABASE_SETUP.md](SUPABASE_SETUP.md).

4. Start dev server:

```bash
npm run dev
```
